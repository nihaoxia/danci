# danci
next.js 单词后台管理系统和h5应用开发

## 应用形式
- 后台管理系统
- h5应用
- 多端开发
## 亮点
- 数据清洗
github 高星的 单词资料库
数据清洗(选择，格式化 ，审核)
- supabase 云端psql数据库
  关系型数据库
- 支持向量数据库
- 云端 BASS 数据库
  Backend as a Service
- ORM 
  不用写sql，不用做数据库的底层处理
  对象关系映射
  todo.save() 保存
  对象和数据库一行记录 对应起来

  - 80% 前端业务组件业务趋同，不用重复造轮子，选用第三方组件库。
  - element-ui / ANT design
  - shadcn 定制性很好，tailwindcss 配合使用
  语义化， ai友好
  按需加载
  - 目录在 components/ui 目录下

    BASS 数据库云服务

    几乎为0
