# 单词学习 H5 需求文档

> 版本：v1.0 ｜ 日期：2026-08-27 ｜ 状态：待评审

## 1. 项目概述

### 1.1 背景

基于已有的单词数据（人教版小学英语单词书 JSON，已导入 Supabase 的 `books` / `words` 表），构建一个移动端 H5 单词学习应用，支持用户登录、浏览单词书、卡片式学习单词、查看单词详情和学习进度。

### 1.2 目标

- 移动端优先的单页 H5 应用，底部 Tab 导航（首页 / 我的）。
- 邮箱 + 密码的登录 / 注册（复用现有 NextAuth Credentials 逻辑）。
- 卡片式单词学习，从上次学习进度继续。
- 单词详情页展示完整词典数据。

### 1.3 技术方案

| 项 | 方案 |
| --- | --- |
| 框架 | Next.js 14（App Router）+ TypeScript，工程基于 `nextjs-typescript-starter` |
| 样式 | Tailwind CSS，移动端优先（max-w-md 容器居中） |
| 认证 | NextAuth v5 beta（Credentials Provider，邮箱 + 密码），复用 `app/auth.ts` / `app/db.ts`（`User` 表）逻辑 |
| 数据库 | Supabase Postgres（复用 `danci/y` 项目的 `books` / `words` 表） |
| ORM | Drizzle ORM |

## 2. 数据模型

### 2.1 现有表（不改动）

**books**（单词书）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | text (uuid) | 主键 |
| title | text | 书名，如「人教版小学英语六年级上册」 |
| wordCount | integer | 单词总数 |
| coverUrl | text | 封面图（可空） |
| bookId | text (unique) | 数据源 bookId，如 `PEPXiaoXue6_1`，关联 `words.bookId` |
| tags | text[] | 标签 |

**words**（单词）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint (identity) | 主键 |
| wordRank | integer | 单词在书中的序号（学习顺序依据） |
| headWord | text | 单词，如 `science` |
| content | json | 词典完整数据（音标、释义、例句、短语、同近义词、同根词等） |
| bookId | text | 关联 `books.bookId` |

**User**（认证用户，由 `app/db.ts` 自动建表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | serial | 主键 |
| email | varchar(64) | 邮箱（登录标识） |
| password | varchar(64) | bcrypt 哈希 |

### 2.2 新增表：study_progress（学习进度）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | serial | 主键 |
| userEmail | varchar(64) | 用户邮箱（关联 User.email） |
| bookId | text | 单词书 bookId |
| lastWordRank | integer | 最近学到的 wordRank |
| updatedAt | timestamp | 更新时间（每次学习自动更新） |

- 唯一约束：`(userEmail, bookId)`，每个用户每本书只有一条进度。
- 「最近学习」模块：按 `updatedAt` 倒序取该用户有进度的书。

## 3. 页面结构与路由

```
/                    首页（Tab 1）：最近学习 + 单词书列表
/me                  我的（Tab 2）：用户信息 / 登录 popup / 学习进度
/study/[bookId]      单词学习页（卡片式）
/word/[bookId]/[rank] 单词详情页
```

全局布局：`app/layout.tsx` 提供移动端容器 + 底部固定 TabBar（首页 / 我的），学习页与详情页保留 TabBar（点击 Tab 可随时离开）。

### 4.4 单词学习页 `/study/[bookId]`

- 入口：首页「继续学习」或点击单词书。
- 起始位置：**最近学到的单词的下一个**（`lastWordRank + 1`）；无进度则从 `wordRank = 1` 开始；已学完则提示「已学完本书」并支持从头复习。
- 展示方式：单词卡片，一次一卡，卡片内容**保持简单**，只展示一个示例句。
- 点击卡片上的**单词本身** → 进入单词详情页。
- 「下一个」按钮切换到下一张卡片；学到的最后一个单词后，`lastWordRank` 更新（服务端 Action 写入 `study_progress`）。

```

│  │    /'saɪəns/           │  │
```

**卡片字段映射**（取自 `words.content` JSON）：

| 卡片元素 | 数据来源 |
| --- | --- |
| 单词 | `headWord`（点击进入详情页） |
| 音标 | `content.word.content.usphone`（为空时用 `ukphone`） |
| 释义 | `content.word.content.trans[0].tranCn` + `trans[0].descCn`（词性） |
| 示例（仅一条） | `content.word.content.sentence.sentences[0]` 的 `sContent` / `sCn` |

**详情页字段映射**：

| 模块 | 数据来源 | 说明 |
| --- | --- | --- |

| 音标 | `ukphone` / `usphone` | |
| 释义 | `trans[]`：`tranCn`、`descCn`（词性）、`tranOther`（英释） | |

## 5. 关键流程

### 5.1 未登录用户点击单词书

```
首页点击单词书 → 跳转 /me → 自动弹出登录 popup
  → 登录/注册成功 → 返回首页 → 再点击单词书 → 进入学习页
```

### 5.2 学习流程

```
进入 /study/[bookId]
  → 读取 study_progress（无则 rank=1，有则 rank=lastWordRank+1）
  → 展示卡片 → 点击「下一个」→ rank+1
  → 每次推进后更新 study_progress.lastWordRank（服务端 Action）
  → 学完全部单词 → 提示完成，可从头复习
```

### 5.3 认证流程（复用现有逻辑）

- 登录：popup 表单 → Server Action → `signIn('credentials', { email, password })`（`app/auth.ts` 中 `authorize` 校验 bcrypt）。
- 注册：popup 表单 → Server Action → `getUser` 查重 → `createUser`（bcrypt 加密）→ 自动登录。
- 会话：NextAuth session 中间件（`middleware.ts`）保护需要登录态的接口。

## 6. 非功能需求

- 移动端优先：以 iPhone 宽度（375px）为基准设计，桌面端居中限宽展示。
- 单词书列表、卡片首屏使用服务端渲染，进度更新用 Server Action + `revalidatePath`。
- 空状态：无单词书 / 无进度 / 无单词时均有兜底文案。
- 密码安全：bcrypt 哈希存储（沿用 `app/db.ts`）。

## 7. 里程碑

| 阶段 | 内容 |
| --- | --- |
| M1 | 全局布局 + TabBar、首页单词书列表（未登录） |

| M3 | study_progress 表、已登录首页（最近学习 + 进度） |
| M4 | 单词学习页（卡片 + 下一个 + 进度更新） |
| M5 | 单词详情页（content 完整渲染 + 发音） |
