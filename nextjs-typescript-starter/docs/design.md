# 单词学习 H5 技术设计文档

> 版本：v1.0 ｜ 日期：2026-08-27 ｜ 关联文档：[proposal.md](./proposal.md)

## 1. 系统架构

```
┌─────────────────────────────────────────────┐
│                浏览器（移动端 H5）             │
│   Server Components  ←  Client Components    │
│   （页面/列表/卡片）      （TabBar/AuthPopup）  │
└──────────────────┬──────────────────────────┘
                   │ RSC Payload / Server Actions
┌──────────────────▼──────────────────────────┐
│         Next.js 14（App Router，Node）       │
│  ┌────────────┐ ┌─────────────────────────┐ │
│  │  NextAuth   │ │     Server Actions       │ │
│  │  v5 beta    │ │  （登录/注册/学习进度）    │ │
│  └──────┬─────┘ └───────────┬─────────────┘ │
│         │     Drizzle ORM   │               │
│  ┌──────▼───────────────────▼─────────────┐ │
│  │            postgres.js 客户端           │ │
│  └──────────────────┬─────────────────────┘ │
└─────────────────────┼───────────────────────┘
                      │ sslmode=require
┌─────────────────────▼───────────────────────┐
│              Supabase Postgres               │
│   books / words / users / study_progress     │
└──────────────────────────────────────────────┘
```

- 渲染策略：页面与列表均为 Server Component，首屏直出；仅交互部分（TabBar 高亮、登录 popup、卡片切换）为 Client Component。
- 数据变更：全部走 Server Actions（`'use server'`），不单独暴露 REST API。
- 数据库：复用 `danci/y` 项目已导入数据的 Supabase 实例，通过 `POSTGRES_URL` 连接（`sslmode=require`）。

### 2.2 已有表（不改动）

#### books（单词书）

```sql
create table public.books (
  id uuid not null default gen_random_uuid (),
  book_id text not null,
  title text not null,
  word_count integer not null default 0,
  cover_url text null,
  tags text[] not null default '{}'::text[],
  created_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now(),
  constraint books_pkey primary key (id),
  constraint books_book_id_unique unique (book_id)
) TABLESPACE pg_default;
```

#### words（单词）

```sql
create table public.words (
  id bigint generated by default as identity not null,
  "wordRank" integer null,
  "headWord" text null,
  content json null,
  "bookId" text null,
  constraint words_pkey primary key (id),
  constraint words_book_id_fkey foreign KEY ("bookId") references books (book_id)
    on update CASCADE on delete CASCADE not VALID
) TABLESPACE pg_default;
```

> 注意：外键 `words_book_id_fkey` 为 `NOT VALID`（历史数据未校验），不影响查询；如需校验可执行 `ALTER TABLE words VALIDATE CONSTRAINT words_book_id_fkey`。列名为驼峰（`"wordRank"` / `"headWord"` / `"bookId"`），Drizzle 会自动加引号，schema 中直接写驼峰名即可。

### 2.3 新增表

#### users（认证用户）

统一用户表，替代 starter 中 `app/db.ts` 内联自动创建的 `User` 表（该表无唯一约束、无时间戳，需要迁移）。

```sql
create table public.users (
  id bigint generated by default as identity not null,
  email varchar(255) not null,
  password text not null,              -- bcrypt 哈希（60 字符）
  created_at timestamp with time zone not null default now(),
  constraint users_pkey primary key (id),
  constraint users_email_unique unique (email)
) TABLESPACE pg_default;

create index if not exists idx_users_email on public.users (email);
```

#### study_progress（学习进度）

```sql
create table public.study_progress (
  id bigint generated by default as identity not null,
  user_id bigint not null,
  book_id text not null,
  last_word_rank integer not null default 0,   -- 最近学到的 wordRank，0 表示未开始
  created_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now(),
  constraint study_progress_pkey primary key (id),
  constraint study_progress_user_fkey foreign key (user_id) references public.users (id)
    on update CASCADE on delete CASCADE,
  constraint study_progress_book_fkey foreign key (book_id) references public.books (book_id)
    on update CASCADE on delete CASCADE,
  constraint study_progress_user_book_unique unique (user_id, book_id)
) TABLESPACE pg_default;

create index if not exists idx_study_progress_user
  on public.study_progress (user_id, updated_at desc);
```

设计说明：

- 用 `user_id` 外键而非 email 字符串关联（proposal 中的 userEmail 方案优化为 FK），保证一致性，删除用户时级联清理进度。
- `unique (user_id, book_id)` 保证每用户每本书一条进度，配合 upsert 写入。
- `updated_at desc` 索引支撑首页「最近学习」排序查询。

### 2.4 Drizzle Schema（`db/schema.ts`）

```ts
import { relations, sql } from 'drizzle-orm';
import {
  bigint, index, integer, json, pgTable, text, timestamp, uniqueIndex, varchar,
} from 'drizzle-orm/pg-core';

export const users = pgTable('users', {
  id: bigint('id', { mode: 'number' }).primaryKey().generatedByDefaultAsIdentity(),
  email: varchar('email', { length: 255 }).notNull().unique(),
  password: text('password').notNull(),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
});

export const books = pgTable('books', {
  id: text('id'), // uuid，由数据库生成，读侧不依赖
  bookId: text('book_id').notNull().unique(),
  title: text('title').notNull(),
  wordCount: integer('word_count').notNull().default(0),
  coverUrl: text('cover_url'),
  tags: text('tags').array().notNull().default(sql`'{}'::text[]`),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
});

// 驼峰列名：Drizzle 生成 SQL 时自动加双引号，与线上 "wordRank"/"headWord"/"bookId" 一致
export const words = pgTable('words', {
  id: bigint('id', { mode: 'number' }).primaryKey().generatedByDefaultAsIdentity(),
  wordRank: integer('wordRank'),
  headWord: text('headWord'),
  content: json('content'),
  bookId: text('bookId'),
});

export const studyProgress = pgTable(
  'study_progress',
  {
    id: bigint('id', { mode: 'number' }).primaryKey().generatedByDefaultAsIdentity(),
    userId: bigint('user_id', { mode: 'number' })
      .notNull()
      .references(() => users.id, { onDelete: 'cascade' }),
    bookId: text('book_id')
      .notNull()
      .references(() => books.bookId, { onDelete: 'cascade' }),
    lastWordRank: integer('last_word_rank').notNull().default(0),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => ({
    userBook: uniqueIndex('study_progress_user_book_unique').on(t.userId, t.bookId),
    userRank: index('idx_study_progress_user').on(t.userId, t.updatedAt.desc()),
  }),
);

export type User = typeof users.$inferSelect;
export type Book = typeof books.$inferSelect;
export type Word = typeof words.$inferSelect;
export type StudyProgress = typeof studyProgress.$inferSelect;
```

### 2.5 content JSON 类型定义（`db/word-content.ts`）

对 `words.content` 定义只读 TS 类型，详情页/卡片按可选字段安全渲染：

```ts
export interface WordContent {
  word: {
    wordHead: string;
    wordId: string;
    content: {
      usphone?: string;          // 美式音标
      ukphone?: string;          // 英式音标
      usspeech?: string;         // 美式发音参数，如 "science&type=2"
      ukspeech?: string;         // 英式发音参数，如 "science&type=1"
      trans?: {
        tranCn: string;          // 中文释义
        descCn?: string;         // 词性，如 "中释"
        tranOther?: string;      // 英文释义
        descOther?: string;
      }[];
      sentence?: {
        desc: string;
        sentences?: { sContent: string; sCn: string }[];
      };
      phrase?: {
        desc: string;
        phrases?: { pContent: string; pCn: string }[];
      };
      syno?: {
        desc: string;
        synos?: { pos: string; tran: string; hwds?: { w: string }[] }[];
      };
      relWord?: {
        desc: string;
        rels?: { pos: string; words?: { hwd: string; tran: string }[] }[];
      };
    };
  };
}
```

解析函数 `parseWordContent(raw: unknown): WordContent | null` 做一次安全转换，渲染层不再处理异常 JSON。

### 3.3 Server Actions

#### `app/actions/auth.ts`

```ts
'use server';

// 登录：复用 starter form.tsx 模式，包装 signIn
export async function loginAction(prevState: string | undefined, formData: FormData) {
  try {
    await signIn('credentials', {
      email: formData.get('email'),
      password: formData.get('password'),
      redirect: false,
    });
  } catch (error) {
    if (error instanceof AuthError) return '邮箱或密码错误';
    throw error;
  }
  revalidatePath('/');       // 登录态变化后刷新首页/我的
  revalidatePath('/me');
  return undefined;          // 成功：popup 关闭
}

// 注册：查重 → 创建 → 自动登录
export async function registerAction(prevState: string | undefined, formData: FormData) {
  const email = String(formData.get('email') ?? '').trim().toLowerCase();
  const password = String(formData.get('password') ?? '');
  // 校验：邮箱格式、密码 >= 6 位，不合法返回提示字符串
  const existing = await getUserByEmail(email);
  if (existing) return '该邮箱已注册，请直接登录';
  const user = await createUser(email, password);   // bcrypt 哈希后插入 users
  await signIn('credentials', { email, password, redirect: false });
  revalidatePath('/'); revalidatePath('/me');
  return undefined;
}

export async function signOutAction() {
  await signOut({ redirectTo: '/' });
}
```

#### `app/actions/study.ts`

```ts
'use server';

/** 点击「下一个」后调用：推进进度（只前进不后退） */
export async function saveProgressAction(bookId: string, wordRank: number) {
  const session = await auth();
  if (!session?.user) throw new Error('UNAUTHORIZED');
  const userId = Number(session.user.id);

  await db
    .insert(studyProgress)
    .values({ userId, bookId, lastWordRank: wordRank })
    .onConflictDoUpdate({
      target: [studyProgress.userId, studyProgress.bookId],
      set: {
        lastWordRank: sql`greatest(${studyProgress.lastWordRank}, excluded.last_word_rank)`,
        updatedAt: new Date(),
      },
    });
  revalidatePath('/'); revalidatePath('/me');
}
```

要点：

- upsert + `greatest()` 保证并发/重复请求下进度单调递增，复习旧词不会回退进度。
- `userId` 从 session 取，不信任客户端传参。

### 3.4 认证与中间件

NextAuth v5 beta（Credentials Provider），`authorize` 内 `compare(password, user.password)` 校验（复用 [auth.ts](../app/auth.ts)）。session 回调需把数据库用户 id 放入 session：

```ts
// auth.config.ts 追加
callbacks: {
  jwt({ token, user }) { if (user) token.id = (user as any).id; return token; },
  session({ session, token }) { if (session.user) session.user.id = token.id; return session; },
}
```

**必须修改 `middleware.ts` / `auth.config.ts` 的 `authorized` 回调**：现有逻辑会把已登录用户从任意页面重定向到 `/protected`，与 H5 场景冲突。改为：

```ts
authorized({ auth, request: { nextUrl } }) {
  const isLoggedIn = !!auth?.user;
  const isProtected = nextUrl.pathname.startsWith('/study');

  if (isProtected && !isLoggedIn) {
    // 未登录访问学习页 → 我的页并自动弹出登录 popup
    return Response.redirect(new URL('/me?login=1', nextUrl));
  }
  return true;   // 其余页面一律放行，登录态由页面内 auth() 区分
}
```

- `/study/**` 为唯一需要登录的路由；首页、我的、详情页公开，页面内用 `const session = await auth()` 区分已登录/未登录视图。
- matcher 保持现状（排除 api、静态资源）。

### 3.5 关键 SQL

```sql
-- 首页「最近学习」（有进度才展示）
select b.book_id, b.title, b.word_count, p.last_word_rank, p.updated_at
from study_progress p
join books b on b.book_id = p.book_id
where p.user_id = $1
order by p.updated_at desc
limit 5;

-- 学习页取当前书全部单词（130 条以内，一次性取回，客户端切换无请求）
select id, "wordRank", "headWord", content
from words
where "bookId" = $1
order by "wordRank" asc;
```

### 4.3 组件设计

#### TabBar（`components/tab-bar.tsx`，Client）

- `usePathname()` 判断当前 Tab：`/` → 首页高亮，`/me` 或 `/me?login=1` → 我的高亮。
- 两项固定：首页 `/`、我的 `/me`。

#### AuthPopup（`components/auth-popup.tsx`，Client）

- Props：`defaultOpen?: boolean`（由 `/me` 读取 searchParams `login=1` 传入）。
- 内部状态：`open`、`mode: 'login' | 'register'`。
- 表单使用 `useActionState(loginAction | registerAction, undefined)`；返回错误字符串则展示，返回 `undefined` 则关闭 popup（`useEffect` 监听 state 变化）。
- 登录/注册共用一套输入框，模式切换仅改标题、按钮文案与提交的 action。
- 提交按钮复用 `app/submit-button.tsx`（`useFormStatus` 显示 pending）。
- 未登录访问 `/me`（含 `?login=1` 跳转）时 `defaultOpen = true`。

#### WordCard（`components/word-card.tsx`，Client）

- Props：`bookId`、`bookTitle`、`words: CardWord[]`、`initialIndex: number`。
- `CardWord` 为服务端预先裁剪好的轻量结构，避免把 130 条完整 content 传给客户端：

```ts
interface CardWord {
  rank: number;
  headWord: string;
  phone: string;        // usphone ?? ukphone
  tranCn: string;       // trans[0].tranCn
  example?: { en: string; cn: string };  // sentences[0]
}
```

- 状态：`index`。点击「下一个」：`setIndex(i + 1)`，同时调用 `saveProgressAction(bookId, words[index].rank)`（fire-and-forget，失败静默，下次进入自动补记）。
- 进度展示 `index+1 / total`；到最后一张时按钮变为「重新开始」（仅重置本地 index，不回退服务端进度）。
- 单词文本为 `<Link href={/word/${bookId}/${rank}}>`，其余区域不可点。

#### ProgressBar（`components/progress-bar.tsx`）

纯展示：`value / total` → 宽度百分比条。

### 4.4 页面数据流

```
首页 page.tsx (Server)

  ├─ 已登录：getRecentLearning(user.id) → 最近学习卡片（Link → /study/[bookId]）

  session = await auth()
  ├─ 未登录：<AuthPopup defaultOpen={searchParams.login === '1'} />

```

## 6. 边界情况与错误处理

| 场景 | 处理 |
| --- | --- |
| 书内无单词（words 为空） | 学习页显示「本书暂无单词」+ 返回首页 |
| `lastWordRank + 1` 超过总词数 | 学习页显示「已学完本书」，按钮提供「从头复习」（仅重置本地 index） |
| 单词 content 缺失/字段为空 | `parseWordContent` 返回 null 或按可选字段跳过对应模块（音标、例句等均为可选渲染） |
| 未登录直接访问 `/study/**` | middleware 重定向 `/me?login=1` |
| 登录密码错误 / 邮箱不存在 | `loginAction` 捕获 `AuthError` 返回中文提示，popup 内展示 |
| 注册邮箱已存在 | `registerAction` 查重后返回提示，不创建 |
| 进度写入失败（网络/未授权） | 静默失败；下次进入学习页由 `getProgress` 计算真实位置，不重复不跳跃 |
| 并发点击「下一个」 | upsert + `greatest()` 保证进度单调 |

## 7. 环境变量与部署

`.env.local`：

```bash
POSTGRES_URL=postgresql://postgres.[ref]:[password]@aws-0-[region].pooler.supabase.com:6543/postgres  # Transaction pooler
AUTH_SECRET=<openssl rand -base64 32>   # NextAuth v5 加密密钥
```

- Supabase 服务端连接建议使用 Transaction Pooler（6543 端口）；`db/index.ts` 中 postgres.js 客户端保持模块级单例，附加 `?sslmode=require`（沿用现有 `db.ts` 写法）。
- 数据库变更：新表（users / study_progress）通过 Supabase SQL Editor 执行 2.3 的 DDL，或在本项目接入 `drizzle-kit push`（沿用 `danci/y` 的 drizzle.config.ts 模式）。
- 已有 `User` 表的历史数据迁移（若存在）：`INSERT INTO users (email, password) SELECT email, password FROM "User" ON CONFLICT (email) DO NOTHING;`，随后 `app/db.ts` 的 `getUser/createUser` 改为操作 `users` 表并删除 `ensureTableExists`。
